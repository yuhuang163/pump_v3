# 图片转换工具使用示例

本文档提供实际的使用示例，帮助快速上手。

## 📁 文件结构

```
overlay/resources/
├── img/                    # 原始PNG图片目录
│   ├── home22.png
│   ├── home32.png
│   └── Battery_50.png
│
└── img_tools/              # 转换工具目录
    ├── baj_to_txt.sh       # BAJ转TXT工具
    ├── png_to_txt.sh       # PNG转TXT工具
    ├── png2baj_fixed.sh    # PNG转BAJ工具（固定参数）
    ├── png2baj_resize.sh   # PNG转BAJ工具（可配置）
    └── jpg2jpg.sh          # JPG格式转换工具
```

## 🎯 常用场景示例

### 场景1：日常批量转换（最常用）

```bash
cd overlay/resources/img_tools

### 1. PNG转BAJ（压缩图片）
./png2baj_fixed.sh ../img/

### 结果：生成 out_img/ 目录，包含所有 .baj 文件
### 例如：home22_360x360_a4_q99_422.baj
```

### 场景2：BAJ转TXT数据文件

```bash
cd overlay/resources/img_tools

### 前提：已有BAJ文件（通过上面场景1生成）

### 2. BAJ转TXT（生成C数组数据）
./baj_to_txt.sh out_img/ -o txt_data/

### 结果：生成 txt_data/ 目录，包含所有 .txt 文件
### 例如：home22_360x360_a4_q99_422.txt
```

### 场景3：PNG直接转TXT（跳过BAJ）

```bash
cd overlay/resources/img_tools

### 直接将PNG转换为TXT数据
./png_to_txt.sh ../img/ -o txt_data_png/

### 结果：生成 txt_data_png/ 目录
### 例如：Battery_50_37x21.txt（文件名自动包含分辨率）
```

### 场景4：单个文件转换

```bash
cd overlay/resources/img_tools

### 转换单个PNG文件
./png_to_txt.sh ../img/Battery_50.png

### 结果：在 ../img/ 目录生成 Battery_50_37x21.txt
```

### 场景5：递归转换子目录

```bash
cd overlay/resources/img_tools

### 假设有如下目录结构：
### images/
### ├── icons/
### │   ├── home.png
### │   └── settings.png
### └── backgrounds/
###     └── bg1.png

### 递归转换所有子目录中的PNG
./png_to_txt.sh images/ -o output/ -r

### 结果：output/ 目录保持相同的子目录结构
### output/
### ├── icons/
### │   ├── home_360x360.txt
### │   └── settings_360x360.txt
### └── backgrounds/
###     └── bg1_360x360.txt
```

```c
    /// ... 更多数据
};

const unsigned int battery_50_icon_size = sizeof(battery_50_icon);
```

```c
/// resources/battery_icons.h
#ifndef BATTERY_ICONS_H
#define BATTERY_ICONS_H

extern const unsigned char battery_50_icon[];
extern const unsigned int battery_50_icon_size;

```

```c
/// ui/battery_widget.c

    }
```
```c
}
```

## 🔄 完整工作流程

### 工作流程A：高性能方案（推荐）

```bash
### 步骤1：准备PNG图片
### 将所有图片放在 overlay/resources/img/ 目录

### 步骤2：PNG转BAJ（压缩+YUV转换）
cd overlay/resources/img_tools
./png2baj_fixed.sh ../img/

### 步骤3：BAJ转TXT（生成C数组）
./baj_to_txt.sh out_img/ -o ../../image_bin/

### 步骤4：在C代码中引用
### 将生成的TXT内容复制到C源文件中

### 步骤5：编译固件
cd ../../../
make -f GNUmakefile firmware
```

**优点**：
- ✅ 文件最小（BAJ压缩）
- ✅ 解码最快（硬件JPEG）
- ✅ 适合大量图片

### 工作流程B：简单方案（小图标）

```bash
### 步骤1：准备PNG图片（小图标）
### 将图标放在 overlay/resources/img/icons/ 目录

### 步骤2：PNG直接转TXT
cd overlay/resources/img_tools
./png_to_txt.sh ../img/icons/ -o ../../image_bin/icons/

### 步骤3：在C代码中引用
### 将生成的TXT内容复制到C源文件中

### 步骤4：编译固件
cd ../../../
make -f GNUmakefile firmware
```

**优点**：
- ✅ 步骤最少
- ✅ 适合小文件

## 📊 输出文件对比

### 测试文件：Battery_50.png (37×21像素)

| 转换方式 | 命令 | 输出文件 | 文件大小 | 格式 |
|---------|------|---------|---------|------|
| 原始文件 | - | Battery_50.png | 417 B | PNG |
| PNG→TXT | `./png_to_txt.sh` | Battery_50_37x21.txt | ~1.3 KB | 十六进制 |
| PNG→BAJ | `./png2baj_fixed.sh` | Battery_50_37x21_a4_q99_422.baj | ~500 B | BAJ |
| BAJ→TXT | `./baj_to_txt.sh` | Battery_50_37x21_a4_q99_422.txt | ~1.5 KB | 十六进制 |

**说明**：
- TXT文件约为原始文件的3倍大小（十六进制文本表示）
- TXT仅用于开发阶段查看和手动嵌入
- 生产环境建议直接使用二进制文件

## 🛠️ 故障排除

### 问题1：提示 "command not found: python3"

**解决**：安装Python 3
```bash
### RHEL/CentOS/Rocky Linux
sudo yum install python3

### Ubuntu/Debian
sudo apt install python3
```

### 问题2：转换失败

**检查**：
1. 确认文件存在：`ls -la input.png`
2. 确认脚本有执行权限：`ls -l *.sh`
3. 查看详细错误信息

### 问题3：输出文件找不到

**检查**：
- 默认输出在源文件同目录
- 使用 `-o` 参数指定输出目录
- 确认输出目录存在或可以创建
