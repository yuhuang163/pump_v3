v3_ui_v7 语言表（按页对照）

怎么加，不要改 ui_*_id.h / ui_lang_bind.h
1. 只改文案：在 en/strings.h 和 zh/strings.h 改同一宏的引号内容。
2. 只改已有控件坐标：在两种语言的 layout.h 改 STEM_Y / _X / _LINE_SPACE / _MAX_W。
3. 新增文案：两种语言的 strings.h 文件末尾追加同名宏，前缀用页面名（HOME_ / PUMP_…）。
4. 新增控件：layout.h 末尾追加 STEM_Y（必要），可选 STEM_X、STEM_LINE_SPACE、STEM_MAX_W；名字里带 ICON 会当成图标。
5. 然后 python3 overlay/ui/v3_ui_v7/lang/tools/gen_ui_lang_tables.py，再 ./pack.sh。
新宏必须追加在文件末尾，插到中间会打乱后面所有 ID，旧语言包会错位。
页面 C 只写宏名。bind 把文案宏变成 ui_str(UI_STR_ID_*)，把 STEM_Y 变成 ui_widget(UI_W_STEM)->y。 圆屏预览：overlay/font/packaging_tools/preview.sh --open 完整说明：docs/architecture/ui/lang-edit.md
