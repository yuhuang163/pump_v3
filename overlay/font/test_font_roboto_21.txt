font_roboto_21 字库配置验证报告
=========================================

1. 位图数据格式：
   - 格式：1bpp (每像素 1 位)
   - 字节序：MSB first (最高位在前)
   - 每字符：19x19 像素，每行 3 字节，共 57 字节
   - 总字符数：62 个 (0-9, A-Z, a-z)

2. 字形描述符 (glyph_dsc):
   - 总数：63 (1个保留 + 62个字符)
   - box_w: 19 (固定，与位图宽度匹配)
   - box_h: 19 (固定，与位图高度匹配)
   - adv_w: 根据实际字符宽度设置 (64-304)
   - ofs_x: 0 (固定)
   - ofs_y: 0 (固定)

3. 字符映射 (cmaps):
   - 映射1: '0'-'9' (Unicode 48-57) -> glyph_id 1-10
   - 映射2: 'A'-'Z' (Unicode 65-90) -> glyph_id 11-36
   - 映射3: 'a'-'z' (Unicode 97-122) -> glyph_id 37-62

4. 字体属性:
   - line_height: 19
   - base_line: 3
   - bpp: 1
   - bitmap_format: 0

5. 测试字符 "L9":
   - 'L' (Unicode 76): glyph_id=22, bitmap_index=1197
   - '9' (Unicode 57): glyph_id=10, bitmap_index=513

如果编译后仍然显示乱码，请检查：
==========================================
1. 确认已重新编译并烧录固件
2. 检查 LVGL 版本 (支持 v7.4+ 或 v8+)
3. 确认头文件 font_roboto_21.h 被正确包含
4. 检查 GNUmakefile 中的编译配置

调试建议：
==========================================
1. 尝试先用 LVGL 内置字体测试，确认 LVGL 工作正常
2. 打印 font_roboto_21 结构体的地址和内容，确认数据正确加载
3. 使用 LVGL 的字体转换工具重新生成字体文件作为对比
